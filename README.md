# Derby: מלחמת האוהדים

בוט טלגרם שבו כל הרשמה היא קול לקבוצה שלך במפקד אוהדים, וקבוצות טלגרם של אוהדים מאתגרות זו את זו לדרבי של ניחושים.

## הפעלה

1. פותחים בוט חדש אצל BotFather ומקבלים טוקן.
2. אצל BotFather: `/setjoingroups` במצב Enable.
3. מריצים על שרת נפרד לפרויקט הזה (פייתון 3.9 ומעלה, בלי התקנות):

```
BOT_TOKEN=הטוקן OWNER_ID=מספר_המשתמש_שלך python3 bot.py
```

את מספר המשתמש שלך אפשר לקבל מהבוט @userinfobot.

## מה הבוט עושה

| מי | פעולה | מה קורה |
|---|---|---|
| משתמש | `/start` בפרטי | בוחר קבוצה, נספר במפקד, מקבל קישור גיוס אישי |
| מנהל קבוצה | מוסיף את הבוט | בוחר איזו קבוצה הקבוצה אוהדת |
| חבר קבוצה | `/derby` | נוצר כרטיס אתגר להעברה לקבוצת האוהדים היריבה |
| קבוצה יריבה | לוחצת "מקבלים את האתגר" | הבוט מתווסף אליה והדרבי פעיל |
| חבר קבוצה | "לנחש תוצאה" | עובר לפרטי, מנחש, נספר לקבוצה שלו |
| כולם | `/table` | מצב המפקד |

ניקוד: תוצאה מדויקת 3 נקודות, כיוון נכון (ניצחון או תיקו) נקודה אחת. ציון קבוצה הוא סכום הנקודות של כל המנחשים בה.

## פקודות של בעל הבוט

```
/addmatch mta hta 2027-01-20 20:30     משחק חדש, שעון ישראל, נשלח לכל הקבוצות הרלוונטיות
/result 1 2 1                          תוצאה למשחק מספר 1: בית 2, חוץ 1
/stats                                 משתמשים, קבוצות, דרבים, ניחושים
```

קודי הקבוצות נמצאים בקובץ `clubs.json`, ושם גם מוסיפים קבוצות ויריבויות.

## מה עוד לא בפנים

- משיכת משחקים ותוצאות אוטומטית ממקור נתונים. כרגע מזינים ביד בשתי פקודות.
- כרטיס תוצאה כתמונה לשיתוף בסטורי. כרגע התוצאה היא הודעת טקסט.
- תשלומים ב-Stars.

## בדיקה

`python3 test_bot.py` מריץ תרחיש מלא מול טלגרם מדומה: הרשמה, גיוס, קבוצה, אתגר, ניחושים, נעילה ותוצאה.
